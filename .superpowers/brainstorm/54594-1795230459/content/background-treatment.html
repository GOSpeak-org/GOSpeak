自定义背景图：哪种呈现处理更对味？

前提（已按推荐默认，可在终端否决）：个人全局背景 · 本地上传 · localStorage 保存 · 深浅色各一张。 图挂在全局 body 层，所有面板之下。关键难点：面板如果完全不透明，背景图就只有缝隙能看见——所以本页对比的是面板透明化的程度。

面板 ≈90% 不透明

A · 轻透保守

面板几乎不动，只把不透明度降到 ~90%，背景图从缝隙与圆角边缘隐约透出。

优点

  • 可读性零风险
  • 改动最小

缺点

  • 背景图存在感弱，功能显得没用
面板 ≈65% + 磨砂

B · 平衡毛玻璃（推荐）

面板降到 ~65-70% 不透明 + backdrop-blur，图的颜色与轮廓透出来，文字仍清晰。侧边栏更透，主面板稍实。

优点

  • 图的存在感与可读性兼顾
  • 与亮/暗两套主题都好调和

缺点

  • 需要为每套主题调一组透明 token
面板 ≈40% 重磨砂

C · 沉浸玻璃拟态

面板大幅透明 + 重磨砂，整窗像一块玻璃浮在图上，图最鲜艳。附带「暗化/模糊强度」可调滑杆兜底可读性。

优点

  • 视觉冲击最强，最「值回票价」
  • 滑杆可适配任意图片明暗

缺点

  • 复杂度最高，重图/低对比下可读性要反复调
  • 八套主题 × 两模式都要验证

补充说明：无论选哪个，无背景图时界面完全回到现状（透明 token 只在有图时启用）； 深色模式同理，只是底色换成深色玻璃。选完这个，下一屏对比「外观设置里的控件形态」。
