改动点清单（全部为视觉层，不碰布局 / 功能 / token）

  • 导航图标质感：荧光绿底加内高光 + 柔和外发光，未选中项仅内高光，层级更清楚。
  • Hero 立体感：紫色渐变加外阴影与内高光，光晕更柔，网格背景与光斑更有空间感。
  • 快捷胶囊：加毛玻璃与 hover 微上浮，提示这是可点区域。
  • 搜索框反馈：内阴影增强凹陷感，聚焦时白色描边 + 柔光圈，输入更"被响应"。
  • 卡片发丝阴影：白卡从纯边框升级为极淡双层阴影，面板浮起但不厚重。
  • 卡片标题装饰线：标题区左侧加 3px 品牌色竖线，强化区块识别，不占布局空间。
  • 输入聚焦反馈：普通输入框聚焦时主色描边 + 柔光圈，与 Hero 搜索框一致。
  • 域行与图标：域行加荧光绿微描边、hover 微上浮；域图标加内高光与柔光，呼应侧栏。
  • 主按钮：所有主色按钮加轻投影，点击层次更明确。
所有增强均可用现有 CSS 变量与工具类实现 · 支持亮/暗主题 · 支持 prefers-reduced-motion 降级
